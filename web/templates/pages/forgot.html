Forgot your password?

composewright sends no email, so a new password is set on the machine it runs on.

  1. Open a terminal there and run:

    composewright password

    If composewright runs in Docker, run it in the container, with your container's name:

    docker exec -it composewright composewright password

  2. Type the new password twice. The command shows your username and signs every browser out.

  3. Sign in with the new password.

Run it as the user composewright runs as, with the same --config and --data-dir if you gave it any.
