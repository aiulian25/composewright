  1. Open the Claude Console and sign in, or create an account. It is separate from a Claude.ai subscription: Claude Pro and Max do not include API use.
  2. Under Billing in the console settings, buy credits; the least is $5. A key does nothing until the account has a balance, and a monthly limit there keeps costs in check.
  3. Open API keys, click Create key, name it composewright and copy it. It starts with sk-ant- and is shown only once.
  4. Paste it under API key below. claude-opus-5-5 is the most capable, claude-sonnet-5-5 cheaper and faster, claude-haiku-5-5 the cheapest.
{{else if eq .ID "openai"}}
  1. Open the OpenAI Platform and sign in. ChatGPT Plus does not include API use.
  2. Under Billing in the platform settings, add a payment method or credits.
  3. Open API keys, click Create new secret key, name it composewright and copy it; it is shown only once.
  4. Paste it under API key below. Any model from their list works if it supports structured outputs.
{{else if eq .ID "ollama"}}
  1. Download Ollama and install it on a machine with a graphics card or at least 16 GB of memory: this one, or another on your network.
  2. Download a model there: ollama pull qwen2.5-coder:7b, or qwen2.5-coder:14b with more memory.
  3. On another machine, let Ollama listen on the network (start it with OLLAMA_HOST=0.0.0.0) and put its address below, such as {{.Example}}. composewright may always reach the model in use.
  4. No key is needed. A small local model reads short prompts best, so keep the budget near 8000.
{{else if eq .ID "gemini"}}
  1. Open Google AI Studio and sign in with a Google account.
  2. Open Get API key, click Create API key and copy it.
  3. Paste it under API key below. The free tier has rate limits, and on it Google may use what you send to improve its products. composewright never sends secrets, but it does send what it read from the repository; paid use does not have that clause.
{{else if eq .ID "openrouter"}}
  1. Sign in to OpenRouter, open Keys, create a key and copy it. It starts with sk-or- and is shown only once.
  2. Pick a model in their list that supports structured outputs and copy its ID. Free ones end in :free and have a daily limit.
  3. Paste the key and the model ID below. If a model does not follow the plan's format, composewright says so and keeps the rules' plan.
{{else}}
  1. Any service that speaks the OpenAI Chat Completions API with structured outputs works: LM Studio, vLLM, Groq and others.
  2. Put its address, usually ending in /v1, and a model it serves below. Add a key if it asks for one.

{{template "icon-download"}}Download a backup

One file with your Settings (the environment profile, the engine, the model providers with their API keys, the appearance) and every project: its versions with their compose.yaml and DEPLOY.md, and its .env with the secrets in it.

Not included: your account, the audit log, the logs of past runs, and what belongs to this install, such as its folders and how it reaches Docker. The passphrase cannot be recovered; keep it apart from the file.

Written to the audit log.

{{template "icon-upload"}}Restore a backup

Brings back the backup's Settings, in place of yours, and its projects. Before any of it runs, it is checked again like everything else.

Written to the audit log.
